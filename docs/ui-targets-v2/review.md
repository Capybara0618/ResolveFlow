## 明确保留的位图差异

没有继续为下列字面反复重画整套图，它们已在图册每项说明及[实施合同](README.md)固定处理方式：

- 04侧栏数字4是生成图示，正式显示当前客户实际待答数；02与04的不同列表不是同时刻共享fixture。
- 10/15生成的0/200、0/500不定义新字符限制；正式限制使用实际契约，字数由真实输入计算。15顶部正式分列材料修订、结果修订、mock/live/unknown和数据来源；来源元数据可展开，无正文明确缺失。
- 19耳机名称和页头RF001329是生成简称，正式取真实商品/申请字段；固定329元和主订单/申请在卡片内一致。明确失败最后一句不得变为突破消费冻结的重新审批/退款入口。
- 状态板与弹窗板可以同时画不同角色/阶段用于说明，实际用户只看属于自己角色及当前状态的一种界面。来源页、政策例文和其余列表不能替代保存的业务数据。

这些是精确文字/数据落地差异，不是新增产品模块或待批准范围。实现时需集中核查，不照图制造字段；用户若调整视觉结构，再更新本设计，不以继续生成图片代替实现。
