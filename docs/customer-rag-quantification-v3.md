# 售后政策RAG扩展评测v3

2026-10-25，按用户授权准备数据、四组检索入口和最终答案评测协议。Agent冻结稿、线上小政策完整读取及旧实验不改。本批不调用生成API，不运行验收题排名。

## 问题与比较对象

旧4文档/66片段/32可答题中dense直接完整@3为90.6%，BM25与RRF+CE均96.9%。旧数据只作回归，不能据此断言融合精排最优。扩展真实售后条件覆盖，检验新方案是否有效，不以降低dense分数或保证提升为编题条件。

目标15份官方HTML、100道作者构造问题。4份沿用原快照，其余新抓取；保存URL、抓取时间、原始字节及正文hash、提取选择器与原文位置。正文为外部参考，不自动成为项目商家政策；未声明生效日期的文档不推断历史适用版本。

## 输入、划分与范围

五类各20题：普通咨询、口语表达、精确条件、组合条款、语料无法回答。每类8开发/12验收，共40开发/60验收；后者不是独立人工盲测，作者已见原文，但在最终方案固定前不运行其排名。按来源组划分：开发来自京东/小米有品3文档，验收来自其他品牌12文档，同一原文事实不跨两组；这有品牌分布差异，不能把开发与验收分数直接当优化前后对照。20题无法回答含8政策缺口和12需要实时业务/私有事实的问题，应获取缺失政策或调用业务工具，而非一律拒绝。实际数量、分层和证据由check核验，不足时报告缺口。

每题写明确品牌/渠道上下文、必要证据组和答案要点/不可承诺项。问题不含Gold段落ID。检索前按品牌和快照版本过滤，所有方法完全相同；不按正确答案所在单篇文档缩小范围。候选数量按实际过滤后的语料报告，不能声称每题都在15份文档中检索。跨品牌干扰不充当权限过滤缺失的收益。

本批完整证据标签由Codex逐条核对原文，记录CODEX_SOURCE_REVIEW；不是商业用户记录或独立人工标签。无法回答题保留缺失项说明，不仅因初次搜索不到就判语料外。所有Gold跨度须能逐字在冻结正文读回。

## 统一的检索与组装

四路：dense、bm25、hybrid-rrf、hybrid-rrf-ce。hybrid只融合正文dense与正文BM25两路，不叠加旧实验标题第三路；词法非正分候选不投票，RRF常数60，每路20候选，融合后最多20供CE。纯向量与BM25使用同样20候选上限。CE复用固定bge-reranker-base及既有CUDA运行时，无新下载/换模型。

正文按同一通用规则切块，保留来源跨度，最多320字符、长块重叠48字符；标题/章节前缀固定且受限。所有方法共用同一索引和组装器。最终使用Top3片段，去除重复跨度，最多8000字符/4096本地tokens；不进行父级扩展，以免把更多正文当排序收益。Top1和Top5只作附加诊断，不以Top5替换Top3主分。不能容纳完整片段时记录跳过，而非无记录截断。

固定用户Query，不使用LLM改写。文档向量预计算，实际每次dense/hybrid重新编码Query；无排名/Query缓存。embedding和CE实际输入须检查token窗口，超限明确失败，不静默截断。

主对照hybrid-rrf-ce对dense；BM25作为强对照并列。模块对照dense→hybrid-rrf与hybrid-rrf→hybrid-rrf-ce分别报告。若BM25持平或更好，保留该结论，不宣称融合精排有普遍优势。

## 指标

主质量：可答题中Top3最终证据包覆盖全部必要证据的比例，称关键证据完整命中率。辅助Top1任一必要证据命中、Top1完整、Top5完整；不能把任一命中或父级展开叫完整Top3召回。语料外题不计入可答分母，候选分数不冒充拒答成功。

质量每题只计一次，时延重复3次。分别报告开发/验收及五类表现，附每题候选和失败；60验收题中的48可答构成最终检索主分母。小样本不承诺具体提升幅度。

时间从Query开始到最终证据包完成，包括Query编码、召回、融合、CE跨进程及组装，不含标签评分、启动/文档编码、HTTP/数据库与答案生成。模型加载、索引构建、GPU型号/精度/窗口、均值/P50/P95、实际正文tokens单列。四路轮换先后，确保相同硬件线程及热态预热。
