## 项目介绍

**ResolveFlow｜基于微服务与 Agent 的电商智能售后平台｜个人项目**

基于微服务与 Agent 的电商售后自动化平台。采用 4 个微服务架构（Gateway 网关、Case 售后服务、Commerce 订单/退款服务、Agent 智能调查服务），通过 RocketMQ 异步消息与 HTTP 同步调用实现服务协作。用户在多商家平台购物下单后，可申请售后退款，Agent 自动调查物流状态、检索退款政策、追问必要材料，生成退款建议提交人工审批，审批通过后由 Java 服务执行可靠退款。覆盖购物、结算、申请、调查、审批、退款的完整业务闭环，实现售后处理自动化。

Agent：Python、FastAPI、AgentScope、MCP、PostgreSQL/pgvector、RAG。

后端 / 前端：Java、Spring Boot、Spring Cloud Gateway、MyBatis、MySQL、Redis、RocketMQ、Vue 3、TypeScript、Docker。

## 七条正文

1. **多租户电商微服务**：采用 Gateway + Case + Commerce + Agent 四服务架构，通过 RocketMQ 异步消息与 HTTP 同步调用实现协作。设计租户隔离架构，商家间数据/政策/权限完全隔离，平台买家可跨店购物。采用 MySQL 乐观锁 + 行级锁保障购物车并发冲突检测与金额一致性，单店订单一次支付原子发布，逐行独立退款互不阻塞。

2. **Agent 自主决策**：基于 AgentScope SDK 构建动态推理-行动循环，按观察结果选择物流读取、政策检索或追问材料。在32个场景中有效建议率87.5%，较固定调查流程业务HTTP读取次数减少17.2%。

3. **政策检索与 RAG**：基于 BGE embedding 与 PostgreSQL/pgvector 检索政策，按订单付款时刻绑定适用版本，过滤商家/品类/版本。外部原始政策文档采用BM25+rerank，Top-3召回率85.8%，较BM25提升4.4个百分点，平均检索2219ms。

4. **版本化授权控制**：通过 input_revision 使补证或人工核验后的旧方案失效并触发新调查；Agent 仅建议，Java 管理授权与预留，审批及消费均复核版本。在8类80次版本失效与竞争实验中，过期授权拦截率100%。

5. **分布式可靠退款**：通过 RocketMQ、Outbox/Inbox 与操作幂等处理消息重投，结合本地状态机和金额预留保障一致性；超时保持 UNKNOWN 并按原操作异步对账。在60次故障试验中，重复退款0笔、超额退款0笔。

6. **Agent Harness 防护**：统一预算守卫、工具白名单及 schema/引用校验，记录 token 预占与结算，以错误反馈驱动有限纠错；通过数据库租约、fence 与持久快照恢复运行。在15组中断对照中，续跑模型请求减少16.4%、token减少12.2%，禁网strict回放18/18包匹配。

7. **Redis 缓存与限流**：针对审核队列采用 Redis 短期缓存与 Semaphore 并发限流；缓存失效或 Redis 故障时有界回源，超限快速失败。在32并发故障压测下，回源并发峰值不超过8；2万工单、30并发下接口p95为18.9ms。
