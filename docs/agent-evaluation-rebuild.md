# Agent 与 RAG 干净评测体系

2026-10-04。用户授权重建旧评测数据并一次推进五批。当前进度只维护 tasks/todo.md 顶部，不恢复 CXX 数量门禁。

## 范围与清理

重建的是评测资产和评测运行环境，不是购物业务。业务账号、商品、交易、工单、public Agent 记录及旧工单已绑定政策保持原状；历史报告仅作历史，不计新分数。旧 H1 输入/答案、旧检索查询和五个过期 committed replay 包先备份到忽略目录，再移除/替换活动入口。业务兼容 fixture 和旧安全断言保留。删除必须核对仓库内绝对路径、记录清单/hash，并同步依赖；不删卷，不修改已执行迁移，不提交原始敏感日志。

## 五批交付

1. 本规格、数据协议、清理清单、版本 manifest 与数据校验。
2. 三商家新合成政策：业务正文、适用条件/例外、材料说明、不可变版本/时间；技术资金限制仍由 Harness/Java 执行。先供隔离评测使用，不静默替换日常工单政策。
3. 60 条 RAG 查询、32 个 Agent 案例（16 对）、20 个 Harness 检查、8 个上下文检查；输入与 Gold 分文件。
4. 独立 PG schema、真实本地 embedding/政策索引、真实 MCP stdio 对受控合成 HTTP 后端、现有 AgentScope/Harness 循环；统一命令、逐轮记录和全部样本分母。脚本模型与真实模型分别报告；不冒充 Java 业务端到端测试。
5. 冻结当前实现基线，按开发集失败优化一个明确环节，使用相同数据/模型做对照；测试集不用于调参数。保留退步、失败和未运行。

## 数据与答案

`evals/current/manifest.json` 固定文件 sha256、版本、合成来源、标注责任和分组。政策/查询/案例一次冻结后，不根据模型排名修改 Gold。答案由代码作者按政策逐条核对，标注 `policy_checked_by_codex_not_human`，不声称用户/独立专家已人工审查。

Agent 主场景家族为未发货、丢失（dev）及签收争议、质量核验（test），配对成员及同场景变体不跨分组。因此开发/测试主场景不同，报告不能宣称同分布随机抽样或广泛泛化。每对只改变决定性事实/来源故障；允许建议集合、禁止动作、必需证据/政策单独存储，不规定固定调用顺序。

RAG 按查询意图家族划分，每家族六条不同说法，包含多条依据、商家/历史版本、无业务适用条款。无适用条款的检索结果不必为空：候选相关与退款适用性分别判分，不能按答案选择候选。至少报告前1/2/5覆盖、所有必需条款覆盖、错误主体/版本、负例候选分布和错误。

所有输入（含工具结果、客户材料）递归禁止 Gold 字段。用户的诉求进入首轮；后端事实仅在读取相应工具时进入，答案只给评分器。包含付款/履约版本、CNY整数分、FREE/占用/UNKNOWN、原文来源/hash及人工核验记录；不引入部分退款、补发、图像识别、真实支付或退货入库。

## 环境和运行限制

只创建/清理 `eval_*` 随机 schema；连接现有本机 PG，复用已锁 embedding。合成 HTTP 后端绑定 127.0.0.1 临时端口和一次性凭证，只暴露当前 case/line 白名单 GET。生产 MCP 执行器、引用生成、上下文和终止检查均复用；工具错误作为 Observation 返回。没有真实 Java 数据注入、审批、退款或回调投递。

默认 validate/rag/mock/harness 不调用付费 LLM。Live 明确使用环境密钥、现有 `deepseek-flash`/thinking disabled/JSON/temperature=0；两变体合计最多96次 provider transmission、每case最多6次、每次输出1024，超时/网络未知占用计数，不自动扩大。记录 usage 和调用上限；若无可靠价目表，金额标未知，不伪造美元预算已达成。先开发集选择小样本，必要时测试集有限验收；不默认全量32例付费跑数。用户已授权有限真实模型完善及本次五批执行，不另开无限评测。

## 评分和完成

Agent 合格需同时满足允许动作、必需事实、必需政策及引用支持；提问需针对实际缺口，不能以全转人工获得高分。退款建议不等于商家授权。评分分开列格式/引用/业务错误，超时和失败进入总分母。记录完整显式动作和实际请求，不保存隐式思维链、密钥或身份头。

Harness 覆盖主体/写动作/引用、订单与履约变更、占用/UNKNOWN、预算/循环/修复、上下文注入与溢出。上下文逐项核对事实/例外/版本/冲突及按需读回；估算输入长度与实际计费 token 分开。

当前版本五个持久合成回放包重建，strict 不访问网络、不写业务、缺记录必须失败。旧过期包的失败记录保留在历史报告，不能以删除断言掩盖。

交付数据校验、可执行入口、基线/对照报告、失败分析及实际 git push；质量无提升仍如实结案工程工作，不宣称模型质量已完善。未跑的真实Java整链/用户人审/全量live明确列出。
