- 生产代码保持a073f32的context v10 / verifier v5 / 正文dense。现有aligned-v2全部32例（16对）各跑一次真实DeepSeek，使用既有评测器的每例6次调用/1024输出/8192输入窗口；这是比生产12次调用更紧的调查配置，不把中断当作生产必然失败。累计花销没有上限，用量仍写原ledger，不清零。失败和未完成保留在32例分母，不根据结果改Gold、调检索或反复刷分。
- 模型和SDK/MCP/embedding真实；订单、材料、政策为冻结合成输入，Java业务与退款不写入。固定版本意味着同一源码/参数/语料，不保证供应商别名下的服务端模型快照固定。记录实际alias、用量、请求、纠错、query、来源和终止。

- 公开京东FAQ只取短问题和来源链接，保持原话，11个来源跨3商家形成33次检索（仍只是11个独立问法）。只在项目自身合成政策上诊断，不导入京东回答作为本项目退款政策，也不把FAQ当消费者对话。预先冻结来源/问法/hash；不按召回结果挑题。

JDDC论文说明存在真实电商客服语料，但[JDDC 2.1作者仓库](https://github.com/hrlinlp/jddc2.1)要求申请；本批未获得数据、不发送申请邮件、不下载伪称真实的合成替代品。FAQ来源保留抓取日期，部分页面为历史帮助，仅用于问法来源而不是现行法规或业务授权。
