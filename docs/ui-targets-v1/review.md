1. 保留现有视觉风格与大部分布局，不重新画全部16张。
2. 优先修08/05/12及相关操作状态，补同一个详情壳的关键变体。必要时合并成状态设计板，避免重复整页。
3. 使用共享角色外壳与同一组示例订单/工单，统一10/11及跨图数据。
4. 对每个主动作明确“入口→确认→提交中→成功/失败→下一状态”。用状态合同验证完整流程，再认为设计可实施。
5. 图片只决定布局/层级；字段、动作和状态由真实接口与领域规则约束。动态错误无需为每一种绘制独立大图，但必须有设计说明。
6. 本次只是审查，不据此恢复暂停的业务实施，也不自动重跑收费生成或DeepSeek调查。
