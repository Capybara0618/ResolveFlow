# Agent 常驻规则、五工具与短引用

2026-10-05，接续已完成的 Context Engineering 第二批。用户批准保留五个 MCP 工具直接可用，精简规则、动作协议及证据引用；不引入工具发现平台，不继续调查策略或 RAG 算法批次。

## 模型看到什么

五工具始终可选，每个只有用途和必要参数：订单付款/金额/履约、承运状态/轨迹、退款状态/金额、客户材料/人工核验、固定政策版本/索引。政策搜索和原文读取仍是已有本地能力，工具名称、权限与实际参数校验不变。没有增加发现工具的模型轮次，没有隐藏固定调查路径。

常驻系统规则保留只读建议、主体绑定、材料指令不可信、证据与推断分离、避免重复、缺证处理、政策依据和金额单位。材料来源/人工核验解释在材料已提供或读到时出现；订单付款/履约解释在订单读取后出现；物流未知/送达语义在物流读取后出现；无候选和政策例外解释在政策搜索后出现。这些是确定性的解释规则，不是生成式摘要或 Harness 替模型做决定。

动作协议仍常驻，但模型不用复制引用的长路径、UUID 或哈希。`PROPOSE` 可写：

```json
{
  "kind": "PROPOSE",
  "case_type": "LOGISTICS",
  "recommended_action": "REFUND",
  "reason_codes": ["LOST_CONFIRMED"],
  "summary": "承运商已确认丢失，符合本店全额退款条件。",
  "evidence_refs": ["O1"],
  "policy_refs": ["P1"]
}
```

例子仅说明模型输入协议，不代表有该运行或可以跳过调查。`review_findings.observation_ids` 也使用已引用的 O 编号；读原文可用 `READ_OBSERVATION` 的 `observation_id=O1`，材料原文仍用 `material:ID`。

## 来源如何保真

- O 编号按当前 run 首次出现的 Observation 顺序生成，P 编号按已检索到的完整政策身份生成；追加记录不重编号。不同版本/hash 的政策有不同编号。
- P2 事实组展示短编号、工具、来源类型、版本、authority；金额/付款/履约/退款占用、状态、冲突和 note 精确保留。政策保留商家 bundle、版本、规则编号、全文、条件和例外。
- 完整 evidence 四字段、policy 五字段存在原始 Observation 和 `ContextPacket.references`；`protected_fact_hash` 继续覆盖原始事实及完整来源。提示词投影不修改原始记录。
- 只有在强制 P2 中呈现的完整来源才能通过短编号用于建议引用。原始客户材料、失败读取、本地读取窗口不会获得可引用身份。窗口可以读取，不会被升级为新的权威证据。
- 每个 SDK run 使用自己的映射。模型/材料不能创建、修改或指定该映射；不存在的编号、证据/政策类型混用均明确拒绝。不根据意图猜引用、不自动增加引用、不到别的运行查找。
- 展开后继续走原 `ModelDecision`、`ProposalVerifier`、Java 契约及审批；完整对象形式仍兼容并逐字段校验。权限、金额、版本、政策主体、缺证和人工最终审批不转移给提示词。

## 恢复、审计和回放

模型账保存原始短编号响应；SDK 接收展开后的动作，最终建议/回调仍使用完整契约引用。映射由同一 run 的已持久 Observation 顺序确定性重建，无额外模型或网络调用，无数据库迁移。实际请求和原始来源记录可以复原每次引用展开。

上下文版本为 `p0-p4-v7-run-short-refs`，计量仍为保守 UTF-8 字节估算和一次包装预留，不能称供应商真实 token。旧 run/回放不能静默换版本；当前回放独立 `evals/replay/context-v4`，增加短引用读回及建议轨迹。旧 v1/v2/context-v3 和 aligned-v2 数据/Gold 保留。

限定的 strict 导出从前序持久工具记录重建读取编号，并核对 canonical 参数 hash；strict 回放继续只使用记录、拒绝缺失/篡改，不启用政策搜索回放或业务写入。

## 验证与边界

集中结果、实际命令、初轮失败及未运行项见[本批报告](../reports/agent-context-protocol/README.md)。至少覆盖短引用展开、缺失/错类型拒绝、哈希/主体校验、材料注入、窗口不能引用、追加稳定、冲突保留、三种崩溃窗口、原始响应持久化和 strict 重现。

五工具无需渐进式发现；本批没有额外 LLM 压缩、RAG 算法调整或收费调用。脚本合成案例通过只证明工程链路，真实模型能否更准确理解新表达仍须另行获得有限 Live 评测授权。运行 worker 没有自动重启，既有工单和数据不重算。
