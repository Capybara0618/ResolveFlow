# RAG当前量化：排名、证据组装与服务速度分开

2026-10-25，用户已冻结Agent文案，要求进入RAG测量。沿用外部原始政策作主实验、BM25为主对照、本店政策作业务补充的已确认方向；不改Agent、原Gold、旧manifest或成绩，不新增生成模型API。

## 为什么另测

既有40题/600请求已测得BM25直接前三完整31/32、旧RRF26/32、两路CE均31/32，不能写混合检索优于BM25。旧外部实验fuse把零分标题/正文词法候选计票；当前生产retrieval过滤词法非正分，两者不一致。已有来源绑定、锚点优先/预算内父级读回的组装模块未在这40题上按相同正文预算和完整流水线计时比较。本轮测通用过滤与组装的实际影响，并保留BM25加同样父级能力的强对照。

## 输入与固定策略

- 复用既有4份固定HTML、66子块和40问题（32可答、8语料外），按原文块/表格行的充分证据集合评分。原数据/标签逐字保持。这是已见数据上的回归与消融，非新独立验收集，不能称40个真实客户问题。
- Query原样输入，不新增LLM改写、多Query扩展、语料下载或重嵌入文档；使用原固定BGE权重/文档向量与CPU4线程。只编码每次检索自己的Query，不以查询结果缓存冒充时延。
- 六路径：BM25-direct、dense-direct、旧RRF-direct、正分RRF-direct、BM25-parent、正分RRF-parent。RRF常数60、每路候选20、入口锚点3/5；这是一致的外部长文实验窗口，不声称与生产短政策窗口5完全相同。
- 正分RRF仅剔除词法score≤0的候选，dense不加阈值；不按题号或Gold过滤。旧RRF保留原零分投票作机制诊断，不作为唯一基线。
- 所有方法共享正文预算8000字符且4096本地tokens。direct只准入完整子块跨度；parent先保留命中跨度，再按既有source/context绑定整体读回可容纳父级，超预算跳过父级。父级选择不接Query/评分标签，保留来源、版本、位置和hash；不增加新关联边。
- 主候选预定正分RRF-parent对比BM25-direct；并列报告BM25-parent，若其同样好且更快，结论应偏向简单方案。dense作为常规纯向量参考、其他路作消融，不能事后挑最佳比较对象冒充预定主对照。CE既有无@3净收益，本轮不重复跑GPU精排网格。

## 指标与时延

主质量指标：最终证据包包含任一充分证据集合的可答题数/32，称“完整证据覆盖率”。另外记录直接前三/前五子块完整覆盖、丢失/新增题、父级准入和实际正文token。展开后不能叫Top-3召回率，也不是最终回答准确率。

六路每题每轮实际检索和组装，40×6×3=720本地请求，轮换路径先后。质量以第一轮32题计，后两轮只看稳定性/计时；8语料外题仅保留候选与不适用边界，不推断拒答率。相同锚点数与上限预算不代表实际返回token相同，实际token一起报告。

时延从Query开始到Top-3入口最终证据包组装及来源校验/分词结束；包括需要的Query编码/候选/融合/组装。Top-5另作非计时诊断，标签评分在计时外。报告平均、P50/P95及120请求/路，模型加载/通用预热单列；不含HTTP、PG、生成答案。旧600计时同时组装K3/K5，与本轮不能直接作加速倍数。

本店补充只读实际PG，用最近Agent记录的政策Query/本店manifest/generation验证当前六规则完整读取，统计该工具的完整返回和平均/分位耗时；原始响应/绑定hash校验，不新增业务写入或模型回答。它与外部长文质量/时延单独列，不能合并成一个线上指标。
