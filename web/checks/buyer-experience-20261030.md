# 买家体验修复（2026-10-30）

用户试用发现十项缺陷。本批分步修复：商品款式与相册、参数/按钮/表单样式、展开层关闭；消息身份；资料/账号/地址和个人中心；登录图片与目录翻页。不得以旧314项通过代替这些交互的真实验收。

## 根因与验收

- 旧工作台 input 规则误选 checkbox，全局 dl 网格误选带行容器的商品参数，全局 hover 强制蓝色；分别收紧选择器，悬停沿用组件色。
