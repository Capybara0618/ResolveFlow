## 行为与实现

- `tab-session.ts`在sessionStorage保留API返回的登录字段和原到期时刻，不保存口令、不写localStorage。刷新读取不会延长过期时间；无效/过期/存储不可用回普通登录或保留当次内存登录。显式退出及原401处理清除存储登录，不删除现有待确认交易/咨询请求。
- App复用同一进入账户函数，恢复本人登录后沿用当前买家路由；商家按原工作台初始化。没有新增自动业务写入或模型请求，API仍按原Bearer权限验证。
- SupportWorkspace按现有owner保存所选咨询/核查单，刷新用GET恢复本人会话，继而订阅原SSE；即使不在列表第一页也按原读取接口恢复。404回可选列表，账号/输入变化不覆盖新选择；已有待确认命令优先，未改变原重试和幂等方式。
- 本步恢复登录和所选咨询，输入框未发送草稿及买家“询问助手/补充商家”切换仍沿用原进入会话默认行为；没有把会话状态包装成所有UI状态持久化。历史助手消息不被新导航实现重写。
