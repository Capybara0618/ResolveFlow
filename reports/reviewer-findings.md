# 审核调查依据分项输出

2026-09-28，审查员优化方案的第二批实现。

## 行为

- Agent可输出来源陈述、模型判断、信息冲突，每项引用本方案内观察ID；冲突要求至少两个不同来源。
- 从AgentScope模型决策、Harness、持久结果回调，到Java接收、共享协议类型和Vue展示保持字段一致。
- Java和Python拒绝引用方案外观察、重复ID、超限/空内容。原有Harness负责来源真实性、版本及权限校验；分项不授予审批或退款权限。
- 审核页面可展开匹配的原始材料，同时显示待补证事项、旧方案失效、服务端复核拒绝原因。
- 工具观察原文尚未投影到审核页面时明确显示缺口，不能用模型摘要冒充原文。历史方案继续兼容。
- 新增共享合成fixture，原有fixture和冻结摘要不改写。

## 集中验证

- 新增测试先失败（协议未声明字段），实现后Python相关185项通过；补充共享fixture测试后该测试文件4项通过。
- Java `CoreContractTest,ProposalReCheckApiTest,AgentCallbackApiTest`：36 passed / 0 failed / 0 skipped，包含共享类型往返、非法来源拒绝、合法分项保存。
- `pnpm --dir web test`：8文件31项通过；`pnpm --dir web build`通过。
- Ruff通过；协议形状与原有回调测试通过。没有运行收费模型，不能据此声称真实模型建议质量提升。
