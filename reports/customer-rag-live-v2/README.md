# 客服RAG真实模型验收 v2

2026-10-21。按[冻结协议](../../docs/customer-rag-live-v2.md)完成12个场景，共30次真实DeepSeek Flash请求。当前政策检索在本组5个需要政策的场景全部取得必要条款，但Agent选择指南、动作格式及失败后交接仍有明确问题。不能称客服整体效果达标。

## 范围与证据

使用当前生产代码的FastAPI ASGI接口→SupportRuntime→AgentScope唯一循环→BoundSources、真实本地BGE和保留PG本店/版本/generation政策，咨询run/call写独立临时schema。订单/物流由[冻结输入](../../evals/customer-rag-live-v2/cases.json)中的历史合成快照通过HTTP MockTransport提供，F02明确返回503。是真实模型业务诊断，不是Java/网页全栈实时联调、真实承运商或商用用户数据；主题与旧开发集重叠，非盲测/独立人工Gold。

输入、12条场景各3项业务标准在模型运行前随准备提交`2df2610`冻结。过程中未修改生产提示词/检索/依赖锁、输入或评分标准，没有按失败重跑新run。Codex根据实际请求、原文与最终回答逐项复核，没有额外模型自评；[语义复核](semantic-review.json)同时保留每项条件、来源和失败层。

## 时间与用量

12项完整Python接口耗时（包含失败、记录开销，排除应用预热；不含Java/浏览器）为1.346–5.635秒，中位2.759秒、描述性P95约5.006秒。样本很小，不是稳定SLA或并发压测。

6次真实政策检索中位74.2ms、描述性P95约81.1ms，范围45.3–81.4ms。两次进程启动预热分别12.31秒和9.06秒，单独保留。12项模型调用耗时合计34.39秒，接口合计37.02秒，说明这批预热后多数等待发生在模型往返，不能据此推断所有负载下的固定占比。

30次调用均保存provider实际usage（estimated=false）：输入35,207、输出1,848 token，不换算未经核验的金额。沿用原累计ledger，从1482到1512，没有重置历史或设新消费上限。模型输出只保留显式动作/答案，没有记录隐式思维链。所有回答引用都可在实际模型请求的已读Observation中回查。
