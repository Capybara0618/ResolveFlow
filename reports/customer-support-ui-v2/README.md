## 双端主布局与交互

SupportWorkspace接入会话列表/中央沟通/右侧上下文，按窗口实际顶部位置计算可用高度，各栏独立滚动，输入框固定在中央底部；仅在两处宿主页增加作用域class，其他商城/售后页面的布局沿用。商品选择和转交确认使用弹层，支持焦点圈定、Escape关闭、返回后保留草稿；来源逐条展开。列表搜索/状态计数明确仅为已加载记录，不假冒全量查询；默认打开首条真实会话或核查单。

保留版本、幂等和不确定请求恢复。修正已转交会话私下追问后收件人被重置为商家的问题；中文输入法确认不误发送，已解决核查单不通过键盘继续发商家回复。订单查询失败与空订单分开显示，弹层可重试。商家报告四区来自现有字段和操作说明，没有额外模型摘要、假调查结果或未确认建议。
