# Harness 与上下文：真实模型对照结果

2026-10-26，用户授权最多700次后，按[冻结执行计划](execution-plan.json)一次运行原16段对话/64回答轮与15组恢复对照。实际新增 **261次** DeepSeek Flash 请求，账本 **3289→3550**，上下文168/恢复93；输入951305、输出35240 token，全部取得provider usage、未知0。没有追加预算、换题补跑或修改生产/旧评分/简历。

核心结论：结构化陈述/事项状态、分层历史与读回使关键上下文检查 **22/32→29/32（68.8%→90.6%）**；已保存模型/工具结果、双方都完成的9组成对故障任务中，中断后新增模型请求 **26→13，减少50%**。后者不包含未保存响应窗口，也不意味着所有中断都能完成恢复。

模型、SDK循环、提示、工具与政策、8192输入/1024输出预算相同。基线只拼本组原始历史，超限移除最早消息；优化组增加生产逻辑实际接受的带来源陈述、事项状态、分层历史和原文读回。第一检查点状态来自各自模型，没有按标准答案预填记忆；原题rubric不进入模型。合成背景未逐轮经过Agent，因此这是机制级检查点对照，不是完整长会话成功率。

典型收益：raw在recall-03漏吊牌、recall-04忘记漏水/杯身/开箱视频；correction-03/04忘记买错颜色/容量小，甚至称客户尚未提出原因。优化组保留这些有效陈述。resume-03的raw正文和实际核查摘要只剩“请给摘要”，优化组实际摘要包含“拉链卡住”。这些是内容源审，不是内部task字段评分。

**不建议在简历宣称上下文压缩降本。** 全组输入减少7.9%，但在双方都通过的22对检查点中，raw191511输入对优化194963，优化反而多1.8%；全组比例混合了两组回答路径与失败差异。收益应写质量保持/事项恢复，不能把结果复用的token降幅混成上下文压缩收益。

## 中断恢复

五个原任务各三个窗口、两组独立前缀，15组配对/30个故障前缀。实际28次os._exit(73)/28次新进程接续；人工核查任务在业务工具窗口两组都只用本地指南完成草稿，未读预设SHIPMENT，故有2条FAULT_NOT_REACHED。原28条均保持deadline、消费预算和manifest，旧执行者拒绝；自有run之外没有修改租约。

两组总分母和所有未命中/失败均保留。未保存窗口恢复明确UNKNOWN_MODEL_RESULT且0新请求，是不确定性停止，不能说100%节省；对应两组各5个prefix仍有STARTED，共10条原journal，不清除/重置。评测侧虽捕获了响应/usage，但生产journal尚未COMPLETE，不能把评测临时记录当成可复用生产结果。

已保存窗口9对全部得到正确结果，恢复后输入71073→39509（减少44.4%，**仅输入token**）；主简历指标优先模型请求50%，不再堆token。其比较限定为原模型/工具调用结果已持久化的窗口，不能把未保存窗口排除后声称“全场景恢复成功”。旧16.4%来自不同Case调查链路/样本，不与新50%拼成前后改进。

从头组未保存窗口policy题虽然技术成功，但把“商家核验签收证明”说成“申请退款前必须先完成商家核验”，多加了原政策/指南不存在的申请前置条件，源审失败。人工核查业务工具窗口的前缀本身生成了正确摘要，但没有触发故障；这是Agent按需用工具的实际路径，不强制读物流来刷故障命中。

## 保留的问题与根因

- 双方resume-02/04第一检查点都存在“同轮新增事项＋暂停＋仍要求MERCHANT_REVIEW”的结构冲突，TurnPlan拒绝；模型一次修正未能稳定解决。优化组resume-02虽第二次理解修正成功，随后用READ_FACTS只读一个事实违反“至少两项、单项用READ_TOOL”，已有修正次数耗尽后停止。raw第一轮同类暂停冲突未修正。不是长历史裁剪造成的这些失败，不能将其都归因记忆。
- 第一检查点未接受有效陈述/事项时，优化组也不能凭空制造记忆：resume-04第二检查点仍丢失缺密封圈故障。说明结构化记忆依赖前置理解质量，不能靠分层窗口修复所有问题。
- raw的no_repeat-01第二检查点把历史“请接着帮我核查”当成本轮operation_request；no_repeat-04发送RESUME但不存在可用前态，均两次输出未修正而失败。这部分差异来自跨轮状态与协议交互，不是纯token压缩。
- 优化组recall-04第二检查点虽完整复述故障/证据，却额外进入退款草稿及签收政策说明。原rubric不因冗长/未执行的额外草稿单独判失败，记录为质量问题；没有宣称已提交，不为这条临时追加新判据。

以上只定位和记录，本轮不改模型提示、生产协议或评测标签追分，不因此扩大任务。原Agent87.5%及RAG84.4%各自冻结证据保持，也没有重测旧strict18包。
